
# Datheon Internship – Task 2: Dynamic Task Manager

A responsive Dynamic Task Manager built using HTML, CSS and JavaScript.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Task categories (Study, Personal, Work)
- Set due dates
- Filter tasks (All, Active, Completed)
- Save tasks using Local Storage
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in Google Chrome.
